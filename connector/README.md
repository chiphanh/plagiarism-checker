# Mono

## How to start

Simply use `python manage.py runserver`. You may also need to run `python manage.py migrate` in order to migrate the DB. Edit the `settings.py` in the **LMS** folder if changes to the DB ports are needed.

## Current usage

Open `http://127.0.0.1:8000/status/`, the buttons are selfexplanatory (kinda).
